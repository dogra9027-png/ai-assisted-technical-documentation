# Nexus IT Operations Platform
## Getting Started Guide

**Document Type:** User Guide  
**Version:** 1.0  
**Audience:** IT Operations Analysts, Administrators, and Viewers  
**Status:** Portfolio Demonstration

---

## 1. Introduction

This guide introduces the Nexus IT Operations Platform and explains how to access the platform, navigate the dashboard, and identify the features available to different user roles.

Nexus is a fictional web-based IT operations platform designed to help organizations monitor infrastructure, review alerts, manage incidents, and access operational reports.

## 2. Intended Audience

This guide is intended for:

- IT Operations Analysts
- System Administrators
- IT Managers and Viewers

The features available to you depend on your assigned role.

## 3. Before You Begin

Before accessing Nexus, ensure that you have:

- A supported web browser.
- An active Nexus user account.
- Your assigned sign-in credentials.
- Network access to the platform.

**Note:** Nexus is a fictional product created for this portfolio demonstration. No live platform or production sign-in service is provided.

## 4. Access the Platform

To access Nexus:

1. Open a supported web browser.
2. Navigate to the Nexus platform URL provided by your organization.
3. Locate the sign-in page.
4. Enter your assigned username.
5. Enter your password.
6. Select **Sign in**.

After successful authentication, the platform displays the dashboard available to your assigned role.

## 5. Understand the Dashboard

The dashboard provides a consolidated view of infrastructure health and operational activity.

Depending on your permissions, the dashboard may include:

| Dashboard Area | Description |
|---|---|
| Infrastructure Health | Displays the operational status of monitored components. |
| Active Alerts | Summarizes alerts requiring attention. |
| Incident Summary | Displays incidents by status. |
| Alert Trends | Provides an overview of alert activity. |
| Operational Reports | Provides access to reporting information. |

## 6. Understand User Roles

Nexus uses role-based access control to determine which features are available to each user.

### Administrator

Administrators can:

- View infrastructure and alerts.
- Acknowledge alerts.
- Create and assign incidents.
- Update incident status.
- View operational reports.
- Manage user accounts and roles.
- Configure monitoring settings.

### Operations Analyst

Operations Analysts can:

- View infrastructure status.
- Investigate alerts.
- Acknowledge alerts.
- Create and assign incidents.
- Update incident status.
- View operational reports.

### Viewer

Viewers can:

- View infrastructure dashboards.
- Review alert information.
- View incident summaries.
- Access operational reports.

Viewers cannot perform restricted administrative or operational actions.

## 7. Navigate the Main Features

### Infrastructure Monitoring

Use the infrastructure monitoring area to review server availability and resource utilization.

### Alert Management

Use the alert management area to review alert details, severity, and status.

### Incident Management

Use the incident management area to track operational issues and review their progress.

### Reporting

Use dashboards and reports to review infrastructure health, alert trends, and incident activity.

## 8. Sign Out

To end your session:

1. Locate your account menu.
2. Select **Sign out**.
3. Confirm that the platform returns to the sign-in page.

Always sign out when using a shared or public workstation.
